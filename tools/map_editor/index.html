Keys

Drag empty map, middle or right button: pan. Wheel: zoom. Click: select (Shift: add). Drag a shape or a handle to move it. Double-click a line or patch edge: add a corner; Alt-click a corner: remove it. Del: delete. Ctrl+D: duplicate. Enter / double-click: finish drawing, Esc: cancel. Ctrl+Z / Ctrl+Y, Ctrl+S, Ctrl+B. 1-9: tools.
